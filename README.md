# Thế Giới Song Song

Không gian tưởng niệm trực tuyến cho người đã khuất, anh hùng liệt sĩ và thương binh.

## Chạy thử

```
python3 -m http.server 8000
```

Mở http://localhost:8000

## Kiểm tra

```
pip install playwright && playwright install chromium
python3 tests/smoke.py
```

## Tài liệu

- `CLAUDE.md`: luật chung cho đội agent (đọc đầu tiên)
- `docs/tam-nhin.md`: ý tưởng, hành trình người dùng, ranh giới
- `docs/tinh-nang.md`: bản đồ file → tính năng
- `docs/do-hoa.md`: chuẩn đồ hoạ, màu, chữ, asset
- `docs/viec-can-lam.md`: danh sách việc theo đợt
- `.claude/agents/`: trưởng nhóm, coder, tester
